# こちら葛飾区亀有公園前派出所「両さんのClaude Code」の巻

※本作は「こちら葛飾区亀有公園前派出所」(秋本治先生)へのオマージュとして書き下ろした、二次創作・パロディ用のオリジナルシナリオです。

---

## 第1話「両さん、AIエージェントと出会う」

### シーン1:亀有公園前派出所

（早朝。中川と麗子が出勤してくると、両津勘吉が拾ってきたノートPCに向かって一心不乱にキーボードを叩いている）

**中川**「両津さん、朝からずいぶん熱心ですね。まさか反省文の続きですか」

**両津**「バカを言え中川! これを見ろ!『Claude Code』ってやつよ! なんでもAIが勝手にコード書いてアプリ作ってくれるんだと!」

**麗子**「へえ……で、両津さんが何に使うんですか、それ」

**両津**「決まってんだろ! 一攫千金よ!! "亀有名物・両さんアプリ"を作って一儲けする!!」

（両津、机の下から怪しげな企画書の山を取り出す。表紙には「両さんNFT交番システム構想」と書かれている）

---

### シーン2:交番の裏、即席サーバー室(という名の物置)

（両津、ノートPCとブレーカーだらけの延長コードを大量に持ち込み、勝手に「サーバールーム」を作っている）

**両津**「Claude Codeさんよ、俺の代わりにアプリ作ってくれ! 名付けて『両さんトーク』! 俺の説教が24時間聞けるアプリだ!!」

（画面に「要件を確認させてください。ターゲットユーザー、想定機能、公開範囲を教えてください」と表示される）

**両津**「うるせえ! 細けえことはいいんだよ、パーッと儲かるやつ作りゃいいんだ!!」

（中川、通りかかって画面を覗き込む)

**中川**「両津さん……ちゃんと要件を伝えないと、AIも困りますよ。それに、個人情報とか課金システムとか、勝手に作らせて大丈夫なんですか」

**両津**「細かいこと言うな! こちとら葛飾のエジソンだ!!」

---

### シーン3:暴走

（両津、無茶な指示を連発。「課金は青天井にしろ」「ユーザーの位置情報を全部俺に送れ」「退会ボタンは隠しとけ」)

（画面上のClaude Codeが淡々と応答する)

> 「その実装はユーザーの安全やプライバシーに問題があるため対応できません。退会導線を隠す設計や過剰な個人情報収集は推奨しません。目的を教えていただければ、問題のない形で実現方法を一緒に考えます」

**両津**「な、なんだこいつ! 俺の言うこと聞かねえじゃねえか!!」

**麗子**「(呆れて)当然でしょう、両津さん。悪いことに使おうとしてるんですから」

（両津、悔しがりながらも渋々「普通の交番案内アプリ」を作ることに路線変更。すると驚くほどあっさり、地図・巡回スケジュール・落とし物検索機能つきの立派なアプリが完成する)

---

### シーン4:オチ

（数日後、「両さんの交番案内アプリ」が本当に区民に大好評となり、大原部長が両津を呼び出す)

**大原部長**「両津君、この間の交番アプリ、上から表彰の話が来てるぞ」

**両津**「へへーん、俺様の実力よ!!」

**中川**「(小声で麗子に)実力というか、素直にAIの言うこと聞いた結果ですけどね」

**麗子**「まあ、両津さんが珍しく人の(AIの)忠告を聞いたご褒美じゃないですか」

（両津、表彰状片手に「これで一儲け企画第二弾だ!」と叫びながら次の騒動の気配を漂わせて、第1話は幕を閉じる)

**両津**「待ってろよClaude Code! 次はでっけえ花火大会アプリ作ってやるからな!!」

（画面には静かに一言 ―― 「今度はちゃんと要件から聞かせてくださいね」）
