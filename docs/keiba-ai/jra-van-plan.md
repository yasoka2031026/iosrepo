# JRA-VAN の契約プラン選定

調査日: 2026-11-08

## 結論

**「JRA-VAN データラボ」(月額2,090円・税込)の1契約だけでよい。** 他のプランやソフトの追加購入は要らない。

- JV-Linkを自作プログラムから使えるのはデータラボだけ。KEIBA-EVの用途(自作collectorによる取得)には、これ以外の選択肢がない
- 同時に使えるPCは2台まで。収集と学習をこのWindows機1台で行うので足りる
- スマホアプリは追加料金なしで使える(UIは自作のPWAなので必須ではない)
- TARGET frontier JV も追加料金なしで使える。データの目視確認に使う
- 有料の個別ソフトは買わない

## 契約の進め方

1. 今週中(11/14の開催より前)に申し込む。最初の開催日のオッズ記録に間に合わせるため
2. 「TARGET(JV-Link)の1カ月無料ダウンロード」の案内がある。自分で購入手続きをしない限り支払いは発生しない、という趣旨の記載がある。無料期間でJV-Linkを導入して動作を確かめ、期間内に購入手続きをする
3. 支払方法はクレジット・スマホ決済(Google Pay・Apple ID)・銀行(楽天・PayPay)・コンビニが案内されている。毎月の払い忘れで記録が止まらないよう、クレジットなどの自動で払える方法を選ぶ

申込画面で確認すること(公式ページでは確認できなかった項目):

- 課金が暦月単位か登録日起算か、月の途中の申し込みが日割りになるか
- 無料期間の対象条件(過去に利用したことがある場合など)
- 解約の締め日

## 設計に効く調査結果

| 項目 | 内容 | 出典 |
|---|---|---|
| 速報系データの提供期間 | **1週間**。1週間を過ぎたデータは取得できない | 開発者コミュニティのJRA-VANスタッフ回答(2026-08-25) |
| 時系列オッズの券種 | 公式FAQでは単複枠・馬連のみ(2023年時点)。2026年には3連複・3連単・ワイドの時系列を取得している利用者の報告もあるが、公式の記載は見つからない | 公式FAQ、開発者コミュニティ |
| 速報オッズの更新間隔 | 最短10秒。当該レースと翌日の前売りは最長120秒、それ以外のレースは610〜710秒 | 公式FAQ(ソフト開発) |
| 過去の時系列オッズの一括取得 | 公式の回答なし | 開発者コミュニティ(2026-10-31の質問) |

設計への反映:

- **collectorは開催日ごとに必ず動かす。** 速報系は1週間で消えるので、起動漏れは翌週の平日までに取り直す
- 3連複・3連単は、時系列オッズの提供に頼らない。速報オッズを自分で定期的に取得して時系列を作る。締め切りが近いレースほど取得間隔を短くする(下限は更新間隔の10秒に合わせる)
- 3連系の時系列オッズが実際に取れるかは、契約後にJV-Linkで確かめる

## 同期先

- Google Drive。アカウントは `keiba-ai/config/sync.local.toml` に記載する(リポジトリが公開のため、コミットしない)
- ログインは、本人が「Google ドライブ for desktop」でそのアカウントに行う
