- 元資料: [sources/x-posts-2026-04_2026-11.md](sources/x-posts-2026-04_2026-11.md)(ユーザー提供。対象期間 2026年4月1日〜11月8日)
- 注意: 各アカウントの数値(回収率・捕捉率など)は投稿者の自己申告であり、本プロジェクトでは検証していない

---

## 1. 結論

X上の開発者は大きく2つに分かれている。

1. **LLMに出馬表を渡すだけの層**
2. **特徴量設計・時系列検証・市場オッズとの比較まで行う層**

本プロジェクトが取り込むのは2の層の「設計と運用の型」である。具体的には、Benter型の市場融合、工程の分離、発走前の記録、確率較正の4つ。

一方、ほぼ全員が「前日〜当日朝に推奨を公開」している。これは本プロジェクトにとって**直前オッズを動かす外部要因**になる。他者の公開予想を、オッズ予測の入力として扱う。

## 3. 「他者の公開予想」を逆手に取る

### 3.1 観察

- カレンは前日、参謀ラティは毎朝、KEIBA TRACE・FINAL8・Cアナライズなどは当日に推奨を公開している
- フォロワーが同じ推奨に乗ると、その馬・組み合わせのオッズは締め切りに向けて下がる
- 能力ベースのAI同士は似た馬を高く評価しやすい。自分の割安判定と重なる可能性がある

### 3.2 対応

1. 主要アカウントの公開◎を、レース詳細画面で手入力できるようにする(X投稿の自動取得は規約確認後)
2. 「公開◎との重なり」を最終オッズ予測の特徴量に入れる
3. 重なる買い目は期待値を割り引く。重ならない割安(他のAIが見ていない穴)を優先する
4. 効果は検証工程で、重なりあり/なしの別に「推奨時点と確定時の期待値の差」を比べて確かめる

## 4. 取り込まないもの

| 内容 | 理由 |
|---|---|
| 自己申告の回収率・的中率の数値 | 検証方法が不明。比較の基準にしない |
| 「LLMに出馬表を渡して予想させる」方式 | 数値予測は勾配ブースティングの方が適している。LLMは説明と対話に限定する |
| 他者の指数・予想文そのもの | 著作権と利用規約の問題がある。使うのは「公開◎がどの馬か」という事実のみ |
